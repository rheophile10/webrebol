Music

The text area has a tune in ABC notation. Push Soft, Organ or Chip to hear the tune with that instrument. All the music code is REBOL text: it reads the ABC notation, calculates the samples, and makes a WAV file for each layer of notes.

You can change the tune in the text area. In the REBOL script below, write the sharp sign of ABC as two carets, because one caret starts an escape in a REBOL string.
