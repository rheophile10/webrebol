WebRebol examples

Each page runs a REBOL script in the browser. The page shows the script below the screen, and you can change it and run it again.

Transitions

  • Reveals: the twelve transitions. Four of them show the letters of a message. Click a card to play its transition again.

Games

  • A pet: feed it, play with it, and let it sleep.
  • Pong: move the paddle with the arrow keys Up and Down.
  • Snake: turn the snake with the arrow keys.

Tools

  • Paint: select a color, a brush or the fill tool, draw with the mouse, and save the picture as a PNG file.
  • SVG: a bar chart that a script makes as SVG elements and as SVG text.
  • Music: write a tune in ABC notation and hear it with three instruments.

Editor

  • The WebRebol page: write a script with layout and view, and push Run.
